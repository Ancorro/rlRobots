# Baselines: reinforcement learning (RL) fine-tuning of small action policies (System 1, the fast action policy, of a vision-language-action model (VLA))

Target: SO-101 arm with SmolVLA (450M parameters). Date compiled: 2026-10-02.

Verification rule: every number below was read from the saved source file in `docs/sources/` (PDF page or README text), not from search snippets. Table numbers are the source's own. "Unverified" or "not reported" means the source does not state it, or the figure could not be read as text.

Hardware abbreviations used in the "fits" notes:
- GTX 1070 Ti = 8 GB video memory (VRAM), Pascal generation, torch 2.7 or older only, no bf16 (bfloat16, a 16-bit number format).
- RTX 4060 Ti = 16 GB video memory (VRAM).
- Oregon State University (OSU) cluster = Oregon State University cluster, A100/H100 (NVIDIA data-center graphics processing units (GPUs); memory per card not verified here).
- "Fits" verdicts are my inference from the cited memory or graphics processing unit (GPU) facts, not measured by us, unless stated.

## Fits our hardware? (per row of Table 1)

Facts used: SmolVLA 450M is trainable on one consumer graphics processing unit (GPU) (SmolVLA paper Sec 4.3: "can easily be trained on a single graphics processing unit (GPU)"; "6x less memory" than pi0, Sec 4.5). All fit verdicts are inference.

1. SimpleVLA-RL: no. A 7B model with full-parameter training on 8 x A800 80 GB. Only the recipe (Group Relative Policy Optimization (GRPO), group size 8, temperature 1.6, drop all-success / all-failure groups) transfers. Oregon State University (OSU) cluster: yes if 8 graphics processing units (GPUs) are available. 1070 Ti and 4060 Ti: no.
2. RLinf-VLA: framework supports flow-matching models and small models (Appendix, Fig 17, figure only: numbers unverified), but its tested configs are 7B OpenVLA with low-rank adaptation (LoRA) on H100s. Oregon State University (OSU) cluster: yes. 4060 Ti: unlikely for the 7B configs. 1070 Ti: no.
3. piRL: no as published (3.3B pi0, 8 x H100). The method is reusable for SmolVLA: SmolVLA-RL (row 4) ported the same Flow-SDE sampler, so a working reference already exists. Oregon State University (OSU) cluster: yes. 4060 Ti / 1070 Ti: no for pi0.
4. SmolVLA-RL repo: closest match to our target. Ran on a 16 GB card; peak video memory (VRAM) 3.3 GiB per training round and 5.4 GiB in the joint-noise probe, but about 25 GB of host memory is needed (README: Limitations, Implementation findings, Reproduction). 4060 Ti 16GB: yes (same class as their 5070 Ti 16 GB, though slower). 1070 Ti: memory fits (under 8 GB) but the README pins torch 2.11 (Compute Unified Device Architecture (CUDA) 12.8), which conflicts with our torch 2.7 or older ceiling on Pascal, and the README says the 99.9M-parameter action expert trains in fp32 (works in favour of a card without bf16); the open question is the dtype of the frozen vision-language backbone on Pascal and whether lerobot 0.6.1 runs there. The bf16 reload bug the README describes was fixed by loading at the stored dtype. Untested by us. Oregon State University (OSU) cluster: yes. Important caution: this repo's result is a null result (no reinforcement learning (RL) gain), and the authors say the null is consistent with too small an update, so it is a negative baseline, not a recipe.
5. diffusion steering via reinforcement learning (DSRL): best fit for the 8 GB card. The paper trained diffusion steering via reinforcement learning (DSRL) against pi0 on an RTX 3070 8 GB with pi0 inference on a remote server (App C.5). Steering SmolVLA means running SmolVLA inference and a small SAC (Soft Actor-Critic) learner on the noise space; SmolVLA inference on 1070 Ti is plausible but unmeasured by us. 4060 Ti: yes. Oregon State University (OSU) cluster: yes (not needed).
6. human-in-the-loop sample-efficient reinforcement learning (HIL-SERL): small convolutional neural network (CNN) plus Soft Actor-Critic (SAC) on one RTX 4090 in the paper; LeRobot ships it for SO-100 / SO-101 (the guide mentions an SO-101 leader arm). 4060 Ti: probably yes (inference; not measured). 1070 Ti: probably workable for 128x128 images (guide recommends 128x128 or 64x64 to save graphics processing unit (GPU) memory); unmeasured. Oregon State University (OSU) cluster: not needed. Needs the real arm and a human present.
7. Squint: single RTX 3090 (memory size not stated in the paper) for 15 min in the ManiSkill3 SO-101 simulation. Memory use not reported: unverified whether it fits 16 GB or 8 GB. 4060 Ti: probably (inference). 1070 Ti: unverified (ManiSkill3 graphics processing unit (GPU) rendering on Pascal untested by us). It is the only source with a ready SO-101 simulation task set and a verified zero-shot real SO-101 result, but it trains a small policy from scratch, not SmolVLA.

## Comparisons and caveats found while verifying

- README misquote (confirmed on the page image of 2509.09674 p13): the SmolVLA-RL README says OpenVLA-OFT rises "from 63.6 to 98.2 percent success on LIBERO-Goal" and builds its "+34.6" comparison on it. In Table 5 the 63.6 -> 98.2 (+34.6) pair is the Spatial column; Goal is 59.6 -> 98.8 (+39.2). The README's own SmolVLA start (62.0) is close to either, but its headline comparison cites the wrong column.
- SimpleVLA-RL's one-trajectory setting is the same starting condition the SmolVLA-RL repo tested (59.6 on Goal, Table 5). OpenVLA-OFT gained +39.2 there; SmolVLA gained -0.70. The SmolVLA-RL README states that model family, reinforcement learning (RL) algorithm, and reinforcement learning (RL) budget also differ, so scale is not isolated.
- piRL text (App C.1) says pi0.5 reaches 98.3 "despite using only a single trajectory for SFT (supervised fine-tuning)", but the same appendix says 40 trajectories were used. We list 40 (the appendix statement). The figure-1 label reads "One-shot supervised fine-tuning (SFT) 43.9" for LIBERO-Long. Treat the "single trajectory" claim as inconsistent in the source.
- piRL Table 6 lists "SmolVLA" on MetaWorld with average 68.2. That equals the 2.25B SmolVLA row in the SmolVLA paper (Table 2), not the 0.45B model (57.3).
- RLinf-VLA claims 98.11 on LIBERO from a 42.09 base trained with low-rank adaptation (LoRA) on all five suites (130 tasks), so its base is weaker than SimpleVLA-RL's full-data supervised fine-tuning (SFT) (91.0); the before-after gaps are not comparable across rows.
- The SO-101 benchmark paper (2606.08881) has no reinforcement learning (RL). It shows SmolVLA at 32.5 average on four real SO-101 tasks with 100 demonstrations each, which is the realistic starting point for an reinforcement learning (RL) fine-tuning attempt (low base success, execution instability dominant). Its Color Sorting task is at 0 to 10 percent for every model, which, if the policy almost never succeeds, risks giving sparse-reward reinforcement learning (RL) no success signal (inference; SimpleVLA-RL Table 7 shows reinforcement learning (RL) gains nothing from a 0 percent start).
- The ManiSkill3 SO-101 integration is Squint (2602.21203). The ManiSkill3 paper itself was not downloaded.

## Could not verify (omitted or marked unverified above)

- Training hours for SimpleVLA-RL, RLinf-VLA (training, not efficiency runs), and piRL: not reported in the text of the PDFs.
- Parameter counts: OpenVLA-OFT in RLinf-VLA (not stated there; 7B comes from SimpleVLA-RL), pi0.5 (not stated separately), Squint, diffusion steering via reinforcement learning (DSRL) diffusion policy, human-in-the-loop sample-efficient reinforcement learning (HIL-SERL) policy.
- RLinf-VLA small-model results (multi-layer perceptron (MLP), flow-matching pi0 extensibility, diffusion steering via reinforcement learning (DSRL) on pi0, Fig 17) are in figures only; no numbers extracted.
- diffusion steering via reinforcement learning (DSRL) LIBERO "20 -> 100" is stated in the text as approximate; the curve itself (Figure 8) was read from text only, and the SO-101-class small-policy numbers are not available.
- LeRobot human-in-the-loop sample-efficient reinforcement learning (HIL-SERL) guide reports no success numbers; the paper's per-task Table 1(a) was garbled in text extraction, so only the average row (49.7 -> 100) and abstract hours (1 to 2.5 h) are used.
- SmolVLA-RL checkpoint-level results (CP0 to CP3 documents in the repo) were not fetched; only the README was read.
- Whether the SO-101 benchmark paper fine-tuned SmolVLA from the 450M base: not stated.
- No paper was found that applies reinforcement learning (RL) to SmolVLA on a physical SO-101 arm. Search did not reveal one; absence is not proven.
